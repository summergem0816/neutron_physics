## Version Notes

### 2026.7.7 `deg-flow-final`

基于 Deg-Flow 修改的最终版本，已经确认流模型不能用，会出现变形以及方格状纹理。

### 2026.7.8 `BSRGAN-1-stage2-with-phy-z-t`

基于 BSRGAN 对第二阶段退化进行了修改，这是第一个版本。除了预测 `Z_t`，还会对应预测每个物理子模块输入的辅助退化参数。

在这个版本的第二阶段推理中，第一阶段物理模块在输入 `z_t` 之后，不会再对 `z_t` 进行 condition 生成来得到每个物理子模块输入的辅助退化参数，而是直接使用第二阶段训练模块预测好的各物理子模块输入辅助退化参数。

### 2026.7.9 `BSRGAN-1-stage2-with-phy-z-t_2`

基于 BSRGAN 对第二阶段退化进行了修改，这是第二个版本，只预测 `Z_t`。

### 2026.7.13 `BSRGAN-1-stage2-with-phy-z-t_3`

基于 BSRGAN 对第二阶段退化进行了修改，这是第三个版本。

对于 `BSRGAN-1-stage2-with-phy-z-t_2`，有一个 `readout_sigma_max` 参数。这个参数默认为 `0.03`，推理结果无噪声；后面改为 `0.5`，推理结果视觉效果与原图差不多，但是噪声分布不太好，所以计算的指标结果较差。

基于之前第二版代码噪声影响较大，所以第三版代码选择使用一个无噪声的物理退化结果 `result_LQ_1`、一个预测的退化信息 `z_t`，这两个是确定性的。关于噪声部分，我们用统计学知识来学，确保它符合分布，但是不做逐像素对比。这里考虑到随机采样的噪声如果做逐像素对比，和真实图像差距太大，容易导致反作用，所以改为用统计学知识来学习。

在复原模型部分，用上述三个信息来进行约束。

### 2026.7.19 `BSRGAN-1-stage2-with-phy-z-t_4`

基于 BSRGAN 对第二阶段退化进行了修改。由于需要对噪声生成部分进行修改，所以对第三个版本进行了备份。

### 2026.7.22 `BSRGAN-1-stage2-with-phy-z-t_5`

基于 BSRGAN 对第二阶段退化进行了修改。由于需要对噪声生成部分进行修改，所以对第三个版本进行了备份。

这一版是对 7.19 修改的更新，噪声生成部分从基础的神经网络改成了 U-net 结构，因此对代码版本进行了更新。
