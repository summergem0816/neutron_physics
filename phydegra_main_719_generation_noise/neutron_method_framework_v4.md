# 中子物理退化模型方法框架（当前 `phydegra_main` 对应版本）

## 1. 方法目标

该版本方法的目标不是直接从一张高质量图像回归任意低质量图像，而是将中子成像退化过程拆成两个相互配合的部分：

1. 内容表征部分  
   负责从高质量图像中提取与物体结构、投影轮廓、透射分布相关的稳定内容信息。

2. 退化表征部分  
   负责从低质量图像中提取与粒子数下降、统计噪声增强、散射背景增强、局部退化分布变化相关的退化状态。

3. 物理前向退化部分  
   负责将高质量图像按照中子成像机理退化为目标粒子数条件下的低质量图像，并显式分解为几何模糊、探测器模糊、散射背景、泊松统计噪声和读出噪声等层。

在整体思路上，该方法保持两阶段训练：

- 第一阶段：学习内容表示、退化表示以及物理前向退化生成
- 第二阶段：学习退化潜变量随退化轨迹 `t` 的连续演化流


## 2. 整体框架

### 2.1 训练阶段一

输入：

- 高质量图像 `I_HQ`
- 对应退化图像 `I_t`
- 退化轨迹参数 `t`

信息流：

1. `I_HQ -> 内容编码分支 E_c -> 内容潜变量 z_c + 多尺度内容特征 H_c`
2. `I_t -> 全局退化编码分支 E_g -> 全局退化向量 e_g`
3. `I_t -> 局部退化编码分支 E_l -> 局部退化特征图 e_l`
4. `(e_g, e_l) -> 退化压缩器 C_d -> 紧凑退化潜变量 z_t`
5. `(z_t, H_c) -> 重建解码器 D -> 重建低质量图像 \hat{I}_t^{rec}`
6. `(I_HQ, t, z_t) -> 物理前向模块 F_phy -> 物理退化图像 \hat{I}_t^{phy}`

这一阶段的目标是：

- 让 `E_c` 学到与退化无关的内容结构
- 让 `E_g + E_l + C_d` 学到退化状态 `z_t`
- 让 `D(z_t, H_c)` 能重建输入的低质量图像
- 让 `F_phy(I_HQ, t, z_t)` 能用物理方式生成与真实低质量图像一致的结果


### 2.2 训练阶段二

输入：

- 同一组样本在五个粒子数水平下的图像：
  - `GT (3e8)`
  - `LQ_50`
  - `LQ_30`
  - `LQ_20`
  - `LQ_10`

对应轨迹位置：

- `GT -> t=0`
- `LQ_50 -> t=0.35`
- `LQ_30 -> t=0.65`
- `LQ_20 -> t=0.80`
- `LQ_10 -> t=1.00`

信息流：

1. `GT -> E_c -> z_c, H_c`
2. `LQ_* -> E_g, E_l, C_d -> z_50, z_30, z_20, z_10`
3. 使用 `{z_c 或 z_0, z_50, z_30, z_20, z_10}` 构造退化轨迹监督
4. 训练 Rectified Flow 学习从清洁端到任意退化时刻的潜空间连续流动

这一阶段的目标是：

- 不再依赖真实低质量输入图像去提取 `z_t`
- 而是仅从高质量端出发，通过给定 `t`，在潜空间中预测对应退化状态 `\hat{z}_t`


### 2.3 最终推理

最终推理时只需要：

- 一张高质量图像 `I_HQ`
- 目标退化位置 `t`

推理流程：

1. `I_HQ -> E_c -> z_c, H_c`
2. `z_c -> Flow(t) -> \hat{z}_t`
3. `(I_HQ, t, \hat{z}_t) -> F_phy -> \hat{I}_t`

因此，推理时不需要真实低质量图像作为输入。  
训练阶段一中使用真实低质量图像提取 `z_t`，是为了建立“退化状态编码器”的监督；训练阶段二完成后，这个 `z_t` 可以由流模型直接生成。


## 3. 内容-退化表示学习模块

### 3.1 内容编码分支 `E_c`

作用：

- 从高质量图像中提取稳定的结构内容
- 保留物体边缘、轮廓、透射分布、几何形态等信息
- 为后续低质量重建和物理退化提供内容参考

输出：

- `z_c`：内容潜变量
- `H_c`：多尺度 skip 特征

这里 `H_c` 主要用于重建解码器，使解码器在生成低质量图像时能够保留正确的结构布局。


### 3.2 全局退化编码分支 `E_g`

作用：

- 编码整幅图像的整体退化强度
- 捕获全局噪声水平、整体信噪比下降、全局对比衰减等信息

输出：

- `e_g`：全局退化向量


### 3.3 局部退化编码分支 `E_l`

作用：

- 编码空间非均匀退化
- 捕获局部散射增强、局部背景抬升、局部清晰度下降等信息

输出：

- `e_l`：局部退化特征图


### 3.4 退化压缩器 `C_d`

作用：

- 将 `e_g` 和 `e_l` 融合为统一的紧凑退化状态
- 得到与第二阶段流模型兼容的低维退化潜变量

输出：

- `z_t`

这里的 `z_t` 可以理解为“当前粒子数条件下该图像的综合退化描述符”。


### 3.5 重建解码器 `D`

作用：

- 验证 `H_c` 与 `z_t` 的分工是否合理
- 强制 `z_t` 真正携带退化信息，而不是仅由内容分支完成全部重建

输入：

- `z_t`
- `H_c`

输出：

- `\hat{I}_t^{rec} = D(z_t, H_c)`

这一路输出不是最终物理退化结果，而是“表征学习监督输出”。  
它的主要作用是约束内容-退化解耦是否有效。


## 4. 物理前向退化模块

该模块按照如下形式构造：

`g = P((S[f] * h_geo * h_det) + b_scatter) + n_read`

其中：

- `f`：高质量图像对应的透射分布
- `S`：源通量/有效粒子数层
- `h_geo`：准直器与成像几何引起的几何模糊
- `h_det`：探测器与闪烁体引起的探测器模糊
- `b_scatter`：散射背景项
- `P`：泊松统计层
- `n_read`：读出噪声层


### 4.1 源通量层 `S`

作用：

- 控制等效粒子数
- 决定图像统计计数水平

控制方式：

- `t` 决定主趋势
- `z_t` 提供小幅修正

当前实现思路：

1. 先根据 `t` 将粒子数映射到基础粒子数 `N_base(t)`
2. 再由 `z_t` 通过一个小型调制头预测修正项 `\Delta_N(z_t)`
3. 得到有效粒子数：
   `N_eff = N_base(t) * exp(alpha * \Delta_N(z_t))`

含义：

- `t` 决定该样本大致处于 5k、3k、2k、1k 这一类退化级别
- `z_t` 用来微调同一退化级别内不同样本的真实退化差异


### 4.2 几何模糊层 `h_geo`

作用：

- 表征准直器发散角和物-探距离引起的几何模糊

初始化参数来源：

- 发散角：`theta_div = 1 deg`
- 物-探距离：`L_od ≈ 50 mm`
- 探测器像素间距：`pitch = 0.66 mm`

初始化方式：

`sigma_geo_mm = L_od * tan(theta_div)`

`sigma_geo_px = sigma_geo_mm / pitch`

按当前参数估算：

- `sigma_geo_mm ≈ 0.873 mm`
- `sigma_geo_px ≈ 1.32 px`

当前策略：

- 用该值作为初始值
- 在训练中允许微调
- 不让 `z_t` 直接控制该层

原因：

- 几何模糊主要由固定成像结构决定
- 不应由粒子数变化直接决定


### 4.3 探测器模糊层 `h_det`

作用：

- 表征像素有限尺寸、闪烁体厚度和探测器响应扩展造成的模糊

初始化参数来源：

- 有效像素宽度：`0.6 mm`
- 像素间距：`0.66 mm`
- 闪烁体厚度：`40 mm`

初始化方式：

1. 先按像素积分效应估计基础模糊：
   `sigma_pixel_mm = 0.6 / sqrt(12)`
2. 转换到像素单位：
   `sigma_pixel_px = sigma_pixel_mm / 0.66`
3. 再与闪烁体扩展项组合，得到初始探测器模糊

当前版本中使用：

- `scintillator_sigma_px_init = 0.35`

并组合为：

- `sigma_det_px = sqrt(sigma_pixel_px^2 + sigma_scint^2)`

同样：

- 以 Geant4 计算结果作为初始化
- 训练中允许微调
- 不让 `t` 和 `z_t` 直接决定该层核宽


### 4.4 散射背景层 `b_scatter`

作用：

- 表征中子散射导致的缓变背景抬升
- 对局部对比度和边缘可见性造成削弱

控制方式：

- `t` 主控
- `z_t` 辅助修正

实现思路：

1. 先对图像做一个大核平滑，构造散射背景基底
2. 再用 `t` 决定散射强度主趋势
3. 用 `z_t` 对散射强度做小幅修正

这是因为：

- 粒子数降低时，散射项和背景占比更明显
- 但不同样本在散射分布上仍可能存在差异


### 4.5 泊松统计层 `P`

作用：

- 表征有限粒子计数下的量子统计波动

控制方式：

- 其统计规模本质上由 `N_eff` 决定
- 因而 `t` 和 `z_t` 的影响已经通过源通量层传递到泊松层中

含义：

- `t` 越大，`N_eff` 越低，泊松波动越强
- `z_t` 的修正会进一步细调某个样本的等效统计水平


### 4.6 读出噪声层 `n_read`

作用：

- 表征探测器电子学噪声、读出噪声等附加噪声

控制方式：

- `t` 主控
- `z_t` 辅助修正

理由：

- 对于低粒子数图像，读出噪声的相对影响更强
- 同时不同样本也可能存在一定偏差


## 5. `t` 和 `z_t` 在物理模块中的作用

### 5.1 `t` 的作用

`t` 是退化轨迹坐标，表示从高粒子数到低粒子数的退化位置。

当前版本中，`t` 不再手工固定指定，而是由粒子数通过对数映射自动计算：

\[
t(N)=\frac{\log N_{max}-\log N}{\log N_{max}-\log N_{min}}
\]

其中：

- `Nmax = 3e8`
- `Nmin = 1e7`

按该规则初始化后，大致对应：

- `GT -> t=0`
- `5e7 -> t≈0.53`
- `3e7 -> t≈0.68`
- `2e7 -> t≈0.80`
- `1e7 -> t=1.00`

`t` 在物理模块中主要控制：

- 有效粒子数主趋势
- 散射背景主趋势
- 读出噪声主趋势


### 5.2 `z_t` 的作用

`z_t` 是从退化图像中提取到的紧凑退化状态。

在物理模块中，`z_t` 不直接重写几何模糊层和探测器模糊层，而是作为辅助修正信息进入：

- 源通量层
- 散射背景层
- 读出噪声层

原因是：

- `h_geo` 和 `h_det` 更偏向固定物理结构退化
- `S / b_scatter / P / n_read` 更偏向统计性、条件性退化

因此当前原则是：

- 固定结构退化：主要由 Geant4 参数初始化并训练微调
- 可变统计退化：由 `t` 主控，`z_t` 辅助


## 6. 损失函数

当前版本阶段一主要使用三类损失：

### 6.1 重建损失

`L_rec = MSE(D(z_t, H_c), I_t)`

作用：

- 监督内容分支和退化分支学到可分离但互补的信息
- 验证 `z_t` 能否与内容特征共同重建目标低质量图像


### 6.2 物理一致性损失

`L_phy = MSE(F_phy(I_HQ, t, z_t), I_t)`

作用：

- 强制物理前向模块生成与真实退化图像一致的结果
- 让 `t` 与 `z_t` 的控制方式逐渐贴近真实中子成像退化机理

需要注意：

- 最终物理退化输出来自 `F_phy`
- `D(z_t, H_c)` 的输出主要是表征学习辅助监督


### 6.3 可选退化正则项

当前代码预留了两项可选正则：

- 全局退化正则
- 局部退化正则

默认系数为 0。  
如果后续发现 `z_t` 不稳定、分布发散或出现退化编码塌缩，可以再打开。


### 6.4 阶段二损失

阶段二主要包括：

1. 流匹配损失  
   约束流模型在潜空间中的速度场拟合真实退化轨迹导数

2. LPIPS 感知损失  
   约束由预测潜变量恢复出的图像在感知层面接近目标低质量图像

3. 物理监督损失  
   当启用物理前向模块时：
   `L_phy_stage2 = MSE(F_phy(I_HQ, t, \hat{z}_t), I_t)`


## 7. 两阶段分别训练什么

### 阶段一训练内容

训练对象：

- 内容编码分支 `E_c`
- 全局退化编码分支 `E_g`
- 局部退化编码分支 `E_l`
- 退化压缩器 `C_d`
- 重建解码器 `D`
- 物理前向模块 `F_phy`

目的：

- 建立“高质量内容”和“退化状态”之间的可分离表示
- 建立 `t + z_t` 到物理退化结果之间的映射

阶段一训练结束后，得到的是：

- 一个能够编码内容的内容分支
- 一个能够从真实低质量图像编码退化状态的退化分支
- 一个能够根据高质量图像、`t` 和 `z_t` 生成低质量结果的物理前向模块


### 阶段二训练内容

训练对象：

- Rectified Flow 潜空间连续退化模型

冻结对象：

- 内容分支
- 退化分支
- 重建解码器
- 物理前向模块

目的：

- 学习如何不依赖真实低质量图像，直接根据 `t` 预测目标退化潜变量 `\hat{z}_t`

阶段二训练结束后，完整推理链条才成立。


## 8. 当前版本与旧版本的主要差异

旧版本：

- 使用共享编码器做弱解耦
- 物理模块主要依赖单一 `effective_t`
- `z_t` 只对退化强度做弱扰动

当前重写版本：

- 使用显式内容分支和显式退化分支
- 将物理退化拆成可解释的多层结构
- 用 Geant4 参数初始化几何模糊和探测器模糊
- 用 `t` 主控统计退化，用 `z_t` 做辅助修正


## 9. 当前代码中的已修复问题

当前版本还同步修复了第二阶段验证指标统计中的 bug：

- 原来验证时先在 GPU 上计算 PSNR
- 又用 CPU 结果覆盖同名变量
- 再将 CPU 张量更新到 GPU metric 中

这会导致设备不一致错误。  
现在验证阶段只保留同设备上的 PSNR 计算与更新。
