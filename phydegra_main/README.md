
## Version Notes

### 2026.7.7 `deg-flow-final`

基于 Deg-Flow 修改的最终版本，已经确认流模型不能用，会出现变形以及方格状纹理。

### 2026.7.8 `BSRGAN-1-stage2-with-phy-z-t`

基于 BSRGAN 对第二阶段退化进行了修改，这是第一个版本。除了预测 `Z_t`，还会对应预测每个物理子模块输入的辅助退化参数。

在这个版本的第二阶段推理中，第一阶段物理模块在输入 `z_t` 之后，不会再对 `z_t` 进行 condition 生成来得到每个物理子模块输入的辅助退化参数，而是直接使用第二阶段训练模块预测好的各物理子模块输入辅助退化参数。
